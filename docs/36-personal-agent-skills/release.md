## 包含内容

- 本机个人资料、长期记忆和 Skill 管理；新建／切换对话，跨会话复用个人知识。
- 自动整理、候选与证据核查、Skill 局部 patch、撤销、历史整理及手动导入导出。
- 修复搜索地址中的括号未编码、被 App 自身导航规则拒绝的问题。

Safari 新浏览界面尚未接入。本包沿用原有内置浏览器，没有把搜索失败自动切换为付费云端搜索，也没有修改 Service 部署。

## 建议装机检查

1. 沿用原来的侧载签名和安装方式覆盖安装，先确认旧记录、课程及聊天仍在。不要通过卸载来验证升级迁移。
2. 确认当前账号已开启内置浏览器／联网搜索。重复之前失败的公共健身资料查询，查看搜索页是否弹出。
3. 页面加载后点「使用搜索结果」，确认 Milo 能继续回答并提供来源；再点来源查看网页。如失败，记录完整提示，并区分是页面打不开、页面已打开但无法提取、还是返回对话后失败。
4. 明确让 Milo 保存一个可复用的方法；收到保存成功提示后进入「Milo 的记忆」检查，换会话再询问相关问题。另测试编辑、撤销和停用。
5. 切换账号时检查知识和会话互相隔离；退出登录后不应继续写入上一个账号的数据。

原生构建和自动测试不能替代真实网页可用性、旧安装升级、文件导入导出和真实模型抽取质量的验证。
