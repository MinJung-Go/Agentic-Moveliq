# 第 37 轮 · 全 App 语义配色提案

状态：2026-10-23 设计已确认，Theme.swift 与原生列表／表单已接入；真机视觉验收待进行。

延续第 33 轮暖白阅读底与深色暖灰。统一的是语义，不是把每个像素都涂成同一种颜色。页面结构差异由间距、分组与字号表达。

| 拟用语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| page | #FFFEFA | #191A18 | 全 App 页面、导航栏、底栏基底 |
| surface | #F3F0E8 | #262723 | 分组、选中行、轻量容器 |
| field | #EFEDE7 | #2B2D27 | 输入框、搜索框、分段底 |
| text | #272723 | #F1F0E9 | 主文字 |
| secondary | #65645F | #B9B9AF | 次要文字 |
| metadata | #77746D | #A4A59A | 日期／来源辅助文字，仅用于满足对比度的底色 |
| separator | #E8E5DE | #363830 | 装饰性分隔线，不单独承担控件辨识 |
| action | #986219 | #E1B373 | 文字操作、当前标签、可交互图标 |
| onAction | #FFFEFA | #191A18 | 实色主按钮内文字 |

品牌 logo 保留原橙色；错误、成功、健康指标及图表类别保留各自语义。按钮不用低对比度浅橙字；图标按钮同时提供可访问名称，不靠颜色表示当前状态。

## 页面映射与例外

- 首页／记录／课程／洞察／设置：page 贯穿导航与内容；分组用 surface，平面列表直接用 page。
- 聊天、会话、记忆：同样的 page，不因进入 sheet 改为蓝灰；原生 sheet 的系统投影与圆角可保留。
- 搜索：App 导航和来源面板用本主题；Safari 网页内容不改色、不注入自定义 CSS。
- 输入框／编辑器：field 作为容器底；聚焦边界用 action，错误配文字说明。
- 全屏照片／视频：保留黑色媒体底；系统授权、系统文件选择器维持系统外观。

## 尺寸与可访问性

- 主体横向内边距 24 pt，窄屏可缩至 20 pt；列表标题与正文共享左对齐基线。
- 正文 17 pt，辅助信息 13–15 pt；动态字体下允许换行，不固定内容高度。
- 交互触控区域至少 44×44 pt；焦点可见；删除不是仅靠红色区分。
- 常规文字对比度目标 4.5:1；焦点、必要控件边界目标 3:1。装饰分隔线允许更淡。
- 色值迁移需检查提高对比度与减少透明度环境，不仅截图比色。HTML 大字号预览不替代 iOS Dynamic Type／VoiceOver 验证。

## 原生迁移约束

以全局 Theme 的语义 token 为维护入口；Journal 保留兼容别名，不能继续复制色值。List／Form 的内容背景与行背景、navigationBar／tabBar 背景、键盘上方安全区都要逐处核对。不得为“统一”破坏媒体预览或分类含义。
